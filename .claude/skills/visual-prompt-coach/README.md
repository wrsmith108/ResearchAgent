# visual-prompt-coach

Design visuals for technical course materials. Applies Dan Roam, Mayer's multimedia principles, C4, cognitive load theory, and Gestalt/CRAP to pick the right visual type and tool (Mermaid or Gemini/Nano Banana), then returns a ready-to-paste prompt plus framework rationale. Use when: design a visual, course diagram, illustration prompt, infographic for lesson, visualize this concept, what diagram should I use, help me prompt an image.
